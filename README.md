# 新闻写作规范 Skill

一套中文新闻 / 消息类写作规范。它既可以作为 AI 写作助手的 Skill 使用，也可以作为人工写作者的案头 checklist。

它只回答一个问题：**一篇合格的新闻稿应该怎么写**——从判断体裁、核对事实、写导语、组织结构，到引语规范、标题拟定、交稿前自查。

## 核心规范

### 一、先定体裁，再动笔

| 体裁 | 特点 | 适用场景 |
|------|------|---------|
| 消息 | 急先锋；简洁明快、要素齐全；时效性最强；倒金字塔；以叙述为主 | 突发事件、动态报道、第一时间传递信息 |
| 通讯 | 深度叙事长卷；细节丰富、描写生动；事实的典型性、思想性、文采合一；不允许虚构 | 人物报道、事件深度还原、风貌展示 |
| 特稿/深度报道 | 在众说纷纭中找到本质主线，梳理因果，还原客观事实；质量不由篇幅决定 | 复杂事件的调查与解释、重大题材开掘 |
| 新闻评论 | 观点＋严密逻辑；立场鲜明、剖析深刻；阐释事物的本质、意义、影响 | 热点事件的是非判断、舆论引导 |

消息是"宣告发生"（简洁、要素、快速），通讯是"讲述故事"（细节、描写、深度）。特稿不是"加长版消息"——把消息注水拉长是大忌。

### 二、5W1H 是检查清单，不是填空模板

何时、何地、何人、何事、何故、如何——用来核对事实是否完备。导语只回答最重要、最有新闻价值的几个 W，其余要素在主体中补齐。忌把六要素机械堆砌成"晾衣绳式"长句。

### 三、导语：硬新闻用直接式

开门见山，第一句即抛出最重要、最具体的事实，只交代最重要最新鲜的部分要素。铁律：导语必须写出事实中最具体、最新鲜的内容，"新方法""重要进展"这类空泛表述是不合格的导语。

检验方法：遮住标题只看导语，读者能否说出这条新闻最重要的事实？

软新闻 / 故事性题材可用延缓式（场景、描写或悬念引入）。

### 四、倒金字塔组织正文

把最重要或最吸引人的信息写在最前面的导语中，之后按信息重要性递减依次写出，越琐碎的细节越靠后。标题 → 导语 → 主体 → 背景 → 结语（结语可有可无）。背景能压缩成一句就不写一段。

检验标准：读者在任何一处停下，都已获得关键信息。

事实段落只做白描陈述，禁用"核心是""关键在于""值得注意的是"这类论断式段落开头；判断如需表达，集中放在背景分析段或结尾一次说完，不在每个段落开头表态。

### 五、引语与消息源

- **直接引语** = 逐字原话 ＋ 引号 ＋ 说话人身份，留给"值得原样呈现"的内容（关键表态、精彩原话）。转述的内容加引号就是造假。
- **间接引语** = 用自己的话转述大意，不加引号，用于压缩概括。
- **归因动词匹配信息实际的发布方式**：正式公告用"宣布/声明称"，采访用"说/告诉记者"，文件数据用"显示"。"表示"本身是纸媒常用中性词，不算错，但不能默认套用。
- **同一消息源确立一次**：导语或首段交代来源后，后续可用"该公司""按计划"承接，不必句句重复归因；多消息源稿件仍须逐条注明来源。
- 凡不是亲眼所见、亲耳所闻的事实，都必须交代来源。禁用"网曝""网传""据说"。

### 六、标题：消息以实题为主

实题叙述新闻事实本身，回答"何人做了何事"，承载可验证的事实信息。底线：题文一致、客观准确、重点突出，不靠误导博眼球。

### 七、新闻语言：白描、简洁、中性

- 多用动词、用准动词；多用子概念（"苹果"不用"水果"）；多用大白话。
- 不让形容词代替事实：写"倒塌房屋37间、转移群众1200人"，不写"非常严重"。
- 删"僵尸词"：模糊程度词（非常/十分）、弱动词＋副词、填充词（其实/事实上）、冗余表达。
- 主观判断边界：不掺杂个人观点；禁用"怒斥""痛批""狂言"这类替说话人定调子的词。

### 八、互联网发布：标签与分隔线

正文结束后空 3–4 行，加一条浅色细分隔线，线下附 3–5 个标签（格式：`标签：A、B、C`）。标签取自正文已出现的事实要素（公司 / 技术 / 地区 / 事件），是内容的索引，不引入正文没有的新概念，不写"重磅""必看"这类情绪词。

### 九、交稿前自查 12 条

1. 观点先行、评论代替事实
2. 背景淹没新闻——可压缩成一句话的背景，就不要写一段
3. 形容词代替事实
4. 面面俱到、不善割舍材料
5. 导语要素堆砌（"晾衣绳式"导语）
6. 导语空泛——写不出"新"在何处
7. 消息来源不明（"网曝""网传""据说"）
8. 伪造或滥用引语——转述加引号、断章取义、煽情动词归因
9. 题文不一、"标题党"
10. 篇幅"裹脚布"——以长为深、注水拉长
11. 事实失实——人名、职称、数字、时间出错；交稿前逐项核对
12. 语言风格不一、前后脱节

## 目录结构

```
news-writing-skill/
├── README.md                  # 本文件：项目介绍与规范摘要
├── SKILL.md                   # Skill 操作核心：写作流程与交付标准
└── references/
    ├── standards.md           # 详细规范：定义、结构、语言、引语、标题、体裁、自查清单
    └── source-report.md       # 来源研究报告：系统调研原文（约 3.5 万字）
```

## 使用方法

**作为 AI Skill 使用**：将本仓库放入 AI 助手的 skills 目录（如 `~/workspace/skills/news-writing/`），写新闻类稿件时调用。`SKILL.md` 是操作核心，`references/` 是详细规范。

**人工使用**：动笔前按"核心规范"走一遍流程，交稿前对照"自查 12 条"过一遍。
